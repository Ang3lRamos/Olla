# Olla

Planeación de comidas para hogares en Colombia: recetas, despensa, menú semanal, lista de mercado, presupuesto en COP y un asistente de IA.

## Desarrollo
1. `npm install`
2. Copia `.env.example` a `.env.local` y completa los valores.
3. `npm run dev`

Más detalles de arquitectura, convenciones y comandos en [CLAUDE.md](CLAUDE.md).
